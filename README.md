# GOI Perfected Joystick
A Getting Over It mod that rewrites the relationship between joystick input and the cursor.
The way joystick input is handled in vanilla GOI is the same pathway the mouse takes;
the stick input is aliased to the mouse input vector and added to the cursor position, fixing the stick to the outside ring results in constant linear motion in the direction of the stick.\
To contrast, with this mod enabled having the stick pushed due east puts the cursor at the right edge of its radius, flick the stick to the left and now the cursor is on the left edge, instantly.
